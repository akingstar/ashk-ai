Quickstart

  1. Open the console. The keyless free route is ready immediately, subject to shared-pool limits. If it is busy, add a free key and retry.
  2. Add free keys for more headroom. Open Keys & settings and paste a free Gemini, Groq or OpenRouter key. ASHK uses them before the shared keyless pool.
  3. Pick an agent or enable Squad. Use Auto for normal work; use Squad for architecture, reviews and anything expensive to get wrong.
  4. Analyze a repo. Go to GitHub Analyzer, paste owner/repo, and run it. No GitHub login is required.

Unlimited on your own machine (Ollama)

A local model has no provider quota: requests never leave your PC. ASHK treats it as the first route in the chain.

  1. Install Ollama from ollama.com/download.
  2. Pull a model that fits your RAM: 
    ollama pull qwen2.5:0.5b   # ~400 MB, runs on ~0.5 GB free RAM
ollama pull qwen2.5:1.5b   # ~1 GB, needs ~1.5 GB free RAM
  3. Allow this site to call Ollama, then restart Ollama: 
    setx OLLAMA_ORIGINS "https://akingstar.github.io"
  4. Open Keys & settings → Custom route and enter: 
    Base URL: http://127.0.0.1:11434/v1
Model:    qwen2.5:0.5b
Key:      (leave empty)

Small models run on a CPU but are noticeably weaker and slower than hosted models; a 7B model needs roughly 8 GB of free RAM. If your browser blocks the loopback call, serve the site locally or put Ollama behind HTTPS.

Honest limits

No hosted AI is truly unlimited. Every provider caps requests, tokens or credits per day. ASHK.AI is free because it never owns a model: it composes free tiers behind one interface and fails over when one runs out.

What “unlimited” means here

No paywall, no subscription and no card on our side. You get as much free usage as the upstream free tiers allow, spread across several providers automatically. For genuinely no caps, run Ollama on your own hardware and add it as a custom route.

Free tiers often train on your data. Never paste API keys, customer data, passwords or private code into a free provider. Add your own keys if you need better control.

Agents & squad

Agents are system prompts with different temperatures and output contracts. Auto mode uses a routing prompt that adapts to the request. Squad mode makes four calls:

plan    → Planner   (deliverables, order, risks)
work    → Analyst   (evidence-led first draft)
critique→ Critic    (flaws, gaps, assumptions)
final   → Writer    (merged, polished answer)

Squad mode costs roughly four times the tokens of a normal message. Use it when quality matters more than quota.

Repo analyzer

The analyzer calls the public GitHub API for repository metadata, languages, README, top-level structure, latest release, contributors and rate-limit headers. It computes a local scorecard, then asks the free model for a structured review. If GitHub rate-limits you, add a fine-grained read-only token in settings; it raises the limit from 60 to 5,000 requests per hour.

Privacy & security

  • No ASHK account and no ASHK backend for chat.
  • Keys are stored in localStorage in this browser only.
  • Prompts go directly from your browser to the provider you configured.
  • The optional Cloudflare gateway is self-hosted by you; its key also stays local.
  • Clear all local data from settings at any time.

A static site cannot hide a shared secret. Never commit provider keys to the repository or place them in source files.

Self-hosting

The frontend is plain HTML, CSS and ES modules — no build step. Fork the repo, enable GitHub Pages for the docs/ folder, and you are live. For a private gateway with Cloudflare Workers AI, see worker/ and deploy.sh in the repository.

git clone https://github.com/akingstar/ashk-ai.git
cd ashk-ai
python -m http.server 8080 --directory docs
# open http://localhost:8080
